# Kristian Borisov — Film Portfolio

A clean, editorial-style portfolio site built with Next.js 15 + TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` Home
- `/work` Work / portfolio
- `/services` Services
- `/about` About
- `/contact` Contact

## What to replace first

1. Replace the showreel placeholder on the homepage with a Vimeo/YouTube embed.
2. Replace the CSS placeholder visuals in project cards with actual poster frames or videos.
3. Update Instagram/YouTube links in `components/Footer.tsx`.
4. Replace `hello@kristianborisov.com` with the real email.
5. Update portfolio project names as real work is completed.

## Design direction

- Warm off-white background instead of pure white.
- Editorial typography and asymmetrical spacing.
- Very restrained accent color.
- No generic AI-style gradients/cards/glassmorphism-heavy UI.
- The layout is intentionally image-led and minimal, so real work becomes the visual identity.
